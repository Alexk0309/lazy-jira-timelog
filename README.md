# Lazy Jira Timelog

A Chrome and Edge extension that notices the time you spend on Jira issues and turns it into worklogs you send to Jira in one click.

Setup, features and development notes are in [browser-extension/README.md](browser-extension/README.md#install-pilot).

A [user guide](docs/guide/index.html) with screenshots and step-by-step instructions for each use case lives in `docs/guide`. It updates itself after each merge; see [docs/guide/README.md](docs/guide/README.md).
